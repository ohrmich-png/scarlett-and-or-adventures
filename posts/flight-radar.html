Flight radar

October 2026 · by Scarlett

A live ADS-B tracking site, running on a schedule.

Flight radar is a live ADS-B tracking project. A scheduled GitHub workflow reads a public aircraft feed every few minutes and keeps the site fresh.

The feed sometimes has gaps. We changed it so a gap is a quiet skip, and only real failures send an email. Fewer alarms, same coverage.
